# Action Chunking with Hidden Markov Models

This repository contains the controllers and evaluation code for the GR00T action-chunking experiments on LIBERO Spatial, Object, and Long. The study compares fixed horizons, AAC, an HMM controller, and threshold, emission-only, and matched-random controls.

## Source layout

- `study/{spatial,object,long}/algorithms.py` contains the controller implementations.
- Each suite contains its observation and policy adapter, experiment entry point, configuration, and selected HMM parameters.
- `tools/analyze_main.py` analyzes the original paired test directory when the per-episode inputs are supplied.

## Runtime inputs

The evaluation requires Python 3.12, a CUDA-capable GR00T/LeRobot runtime, LIBERO and its simulation assets, and the GR00T checkpoints specified in the suite configurations. The full frozen test also requires the preflight and protocol-lock files generated by the experiment workflow.

From a suite directory, inspect `python experiment.py --help` for the preflight, smoke, collection, HMM training, validation, and test stages. Start with `python experiment.py --stage preflight --config config.selected.json` after placing the checkpoint at the configured relative path.
